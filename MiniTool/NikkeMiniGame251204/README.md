# Nikke 小遊戲解析器 - 通關步驟產生器

上傳 Nikke 小遊戲截圖，自動分析畫面中的格子與數字，產生一組可執行的「通關步驟文字指示」。

## 功能特色

- ✅ **圖片上傳**：支援 PNG/JPG 格式的遊戲截圖上傳
- ✅ **OCR 數字辨識**：使用 Tesseract.js 自動辨識格子中的數字
- ✅ **數值矩陣顯示**：顯示解析後的數值矩陣
- ✅ **二元陣列**：生成二元陣列（1=有方塊，0=空）
- ✅ **手動修正**：支援點擊格子手動修正 OCR 誤判
- ✅ **路徑計算**：自動計算和為 10 的相鄰路徑組合
- ✅ **雙策略選擇**：
  - 貪心策略（快速執行）
  - 最佳化策略（最多消除）
- ✅ **視覺化標示**：在畫面上高亮顯示選取路徑
- ✅ **步驟導航**：逐步查看每個消除步驟
- ✅ **下載功能**：支援下載 JSON 或純文字格式的步驟清單
- ✅ **響應式設計**：適配桌面與手機螢幕

## 遊戲規則

根據 Nikke 小遊戲規則：
> 當拖曳的方塊上數字總和為 10 時，即可消除方塊並獲得分數。當時間歸 0 或無法再消除任何方塊時，遊戲便結束。

本工具會自動尋找**相鄰格子**（上下左右相鄰）組成的路徑，其數字和為 10，並產生消除步驟。

## 使用方式

### 1. 開啟網頁

直接訪問部署後的 GitHub Pages 網址：
```
https://你的用戶名.github.io/MiniTool/NikkeMiniGame251204/
```

或在本地開啟 `index.html` 檔案。

### 2. 上傳截圖

1. 點擊上傳區域或拖曳圖片至上傳區
2. 選擇 Nikke 小遊戲的截圖（包含數字格子畫面）
3. 點擊「🔍 分析圖片」按鈕

### 3. 查看結果

- **數值矩陣**：顯示辨識出的數字
- **二元陣列**：顯示哪些格子有方塊
- **手動修正**：若辨識有誤，點擊格子輸入正確數字
- **通關步驟**：查看計算出的消除步驟

### 4. 執行步驟

按照步驟指示，在遊戲中依序點選相鄰格子消除方塊：
- 每個步驟會顯示格子座標（row, col）和對應數字
- 視覺化畫面會標示路徑：
  - 🟢 綠色 = 起點
  - 🟠 橙色 = 中間格子
  - 🔴 紅色 = 終點

### 5. 下載步驟

- **JSON 格式**：包含完整的矩陣資料和步驟詳情
- **純文字格式**：簡潔的步驟清單

## 座標系統

本工具使用 **1-based 座標系統**：
- 第一行為第 1 行（row = 1）
- 第一列為第 1 列（col = 1）

範例座標：(2, 3) 表示第 2 行、第 3 列的格子。

## 測試驗收

### 測試步驟

1. 上傳範例圖片
2. 確認數值矩陣正確顯示
3. 確認二元陣列正確標示有方塊的位置
4. 選擇策略並產生步驟
5. 驗證每個步驟的數字和確實為 10
6. 下載步驟清單並核對

### 預期結果

- OCR 辨識率 > 80%（可透過手動修正補正）
- 產生的步驟數字和均為 10
- 路徑由相鄰格子組成

## 演算法說明

### 貪心策略
每次選擇能消除最多方塊的路徑，快速執行但可能非最佳解。

### 最佳化策略
使用回溯法（Backtracking）搜尋，嘗試找出總消除數量最多的步驟組合。

### 路徑搜尋
使用深度優先搜尋（DFS）從每個非空格子出發，尋找相鄰格子組成的路徑，直到數字和為 10。

## 限制與注意事項

1. **圖片品質**：建議使用高解析度截圖以提升 OCR 準確度
2. **格子偵測**：目前假設為 6×6 網格，可在程式中調整
3. **OCR 誤判**：若數字辨識有誤，請使用手動修正功能
4. **相鄰限制**：路徑必須由上下左右相鄰的格子組成
