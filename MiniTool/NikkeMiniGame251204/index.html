📖 使用說明

遊戲規則：當拖曳的方塊上數字總和為10時，即可消除方塊並獲得分數。

📷 上傳圖片模式：

  1. 上傳 Nikke 小遊戲的截圖（包含數字格子畫面）
  2. 系統會自動偵測格子位置並使用 OCR 辨識數字
  3. 若辨識有誤，可點擊格子手動修正
  4. 選擇策略後，系統會產生消除步驟
  5. 按照步驟指示，在遊戲中依序點選相鄰格子消除方塊

⌨️ 手動輸入模式：

  1. 切換到「手動輸入」標籤
  2. 貼入 JSON 格式的二維陣列，例如：[[1,2,3],[4,5,6],...]
  3. 系統會自動判斷尺寸（如 10×16）
  4. 若偵測到需要轉置（如 16×10），可點擊「一鍵轉置」按鈕
  5. 格子數值僅允許 0-9

注意：路徑必須由相鄰格子組成（上下左右相鄰）。座標系統使用 1-based（第一行/列為1）。
